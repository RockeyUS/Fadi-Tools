## Fadi Tools

Fadi Tools is an all-in-one Windows app: convert files, compress videos and pictures, edit photos and videos, work with PDFs, inspect files and download from the internet. It works offline, it's free, and it's in English and Arabic.

**Download:** get **Fadi.Tools.zip** (everything included), unzip it and open **Fadi Tools.exe**. Or get **Fadi.Tools.exe** on its own; it downloads its engines (about 50 MB) the first time.
If Windows says "Windows protected your PC", click **More info → Run anyway**.

## What's new in 1.0.1

### Added
- **Avatar size preset (1 MB)** in Compress, for profile pictures on GitHub, forums and other sites.
- **Size limits now work for every picture type** (PNG, JPG, WEBP, GIF, HEIC, AVIF, TIFF). The picture keeps its format and gets the best quality that fits. If it's still too big, it gets slightly smaller and the list shows the new size.

### Improved
- **Setup is much faster.** Both engines now download at the same time, from faster servers, over several connections at once, and are a third of the size (about 50 MB instead of 150 MB).
- **Uses about 330 MB less disk space.** Only the 3 engine programs Fadi Tools actually uses are kept; extra copies from older versions are removed automatically.
- **The portable .zip is about half the size.**
- **One program file:** the app is now always called **Fadi Tools.exe**. The old FileConverter.exe is replaced automatically.

### Fixed
- Compressing a picture that was only a little over a size limit (for example 1.1 MB with a 1 MB limit) said "Already small" and kept the original. It now makes the picture fit.
- PNG pictures ignored the size limit.
