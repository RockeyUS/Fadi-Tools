## Fadi Tools

Fadi Tools is an all-in-one Windows app: convert files, compress videos, edit photos and videos, work with PDFs, inspect files and download from the internet. It works offline, it's free, and it's in English and Arabic.

**Download:** `Fadi.Tools.zip` has everything ready to use. Unzip it and open **Fadi Tools.exe**. If Windows says "Windows protected your PC", click **More info → Run anyway**.

## What's in 1.0.0 (first public release)

### Added
- **Convert** pictures, audio, video, documents and data files
- **Studio**: photo editing (text, background removal, crop) and a video timeline (split, reorder, transitions, speed, music, timed text, auto captions, saved projects)
- **Compress** with one-click Discord, Email and WhatsApp sizes
- **PDF tools**: combine PDFs and photos; reorder, rotate, delete, split and save pages as pictures
- **Copy text from pictures** (Arabic and English, offline)
- **Download** from YouTube and 1,000+ sites
- **File inspector** and **Reverse engineer**
- **Activity panel**, taskbar progress and Windows notifications when work finishes
- **Ctrl+K quick search** and a **right-click menu** in File Explorer
- **Crash safety**: Studio work is backed up and offered back after a crash
