# Fadi Tools website (test)

This folder is the website: `index.html`, `img/` (the app's own screenshots from the released version, as WebP, and the logo) and `.nojekyll`.

To put it online: commit and push this `docs` folder, then on GitHub open the repository's Settings → Pages, choose "Deploy from a branch", branch `main`, folder `/docs`, and Save. After a minute it's at https://rockeyus.github.io/Fadi-Tools/

- English and Arabic (the button at the top remembers the choice; Arabic browsers start in Arabic).
- Light and dark follow the visitor's system, and the screenshots switch with it.
- Every download button goes to the latest release, so the page never needs a version number.
- It only lists what's in the released version.
